# 테마 주식 리서치 에이전트 요구사항 초안

## 1. 서비스 목적

사용자가 입력한 주식 테마와 시장을 기준으로 공개 정보를 조사해, 테마 관련 근거가 확인된 종목 후보와 정량 비교 결과를 제공한다. 이 서비스는 투자 판단을 돕는 리서치 보조 도구이며 매수·매도 추천을 제공하지 않는다.

## 2. 대상 사용자와 문제

- 대상 사용자: 특정 산업 또는 투자 테마를 빠르게 조사하려는 개인 사용자
- 해결할 문제: 종목별 테마 관련 근거와 가격·재무 정보를 여러 공개 출처에서 직접 확인해야 하는 불편

## 3. MVP 핵심 기능

1. 사용자는 `theme`, `market(KR/US)`, `period`, `top_n`을 입력할 수 있다.
2. 시스템은 공개 공시, IR, 공식 보도자료 등을 근거로 테마 관련 종목 후보를 제시한다.
3. 종목별 테마 연결 근거와 출처 URL, 문서 제목, 발행일을 함께 표시한다.
4. 기간 수익률, 변동성, 최대낙폭(MDD), 거래량 변화와 공개 가능한 재무 지표를 비교표로 제공한다.
5. 결과에는 데이터 기준일, 계산 방법, 데이터 한계 및 투자 유의사항을 표시한다.

## 4. 입력·출력 기준

- 필수 입력값이 누락되거나 모호하면 임의로 분석하지 않고 사용자에게 확인한다.
- KR 시장은 한국 상장 보통주, US 시장은 미국 거래소 상장 보통주를 기본 대상으로 한다.
- ETF·ETN·우선주·SPAC·OTC 종목은 사용자가 명시적으로 요청한 경우에만 포함한다.
- 비교 결과에서는 `N/A`, `N/M`, `비공개`, `확인 불가`를 구분해 표시한다.

## 5. 제약 및 안전 원칙

- 접근 제한 또는 유료 자료를 우회하지 않고 공개적으로 확인 가능한 정보만 사용한다.
- 출처 없는 수치나 추정을 사실처럼 표시하지 않는다.
- API 키·개인정보 등 민감정보를 저장하거나 출력하지 않는다.
- 결과 끝에 과거 데이터가 미래 성과를 보장하지 않으며 투자 조언이 아니라는 안내를 포함한다.
