# 테마 주식 리서치 에이전트 요구사항 정의서

## 1. 문서 목적

이 문서는 **테마 주식 리서치 에이전트**의 MVP(최소 기능 제품) 요구사항을 정의한다. 사용자가 입력한 주식 테마와 시장, 분석 기간을 바탕으로 공개 정보에 근거한 종목 후보와 정량 비교 결과를 제공하는 것이 목적이다.

본 서비스는 투자 판단을 보조하는 정보 제공 도구이며, 특정 종목의 매수·매도·보유를 권유하거나 수익을 보장하지 않는다.

## 2. 문제 정의

테마 투자에 관심 있는 사용자는 관련 종목을 찾고 비교하기 위해 여러 공시, 기업 자료, 가격 데이터, 뉴스를 직접 확인해야 한다. 이 과정은 다음과 같은 어려움이 있다.

- 기사 언급만으로 테마 관련 종목을 판단해 사업 연관성이 불명확할 수 있다.
- 종목별 가격 성과와 재무 지표의 기준일·단위·산식이 달라 비교가 어렵다.
- 출처와 계산 기준이 남지 않아 결과를 다시 검증하기 어렵다.

서비스는 공개적으로 접근 가능한 근거를 수집·정리하고, 동일한 기준의 비교표와 한계를 함께 제공해 이 문제를 줄인다.

## 3. 서비스 목표와 대상 사용자

| 구분 | 내용 |
| --- | --- |
| 대상 사용자 | 특정 산업·기술·정책 등 주식 테마를 빠르게 조사하려는 개인 리서치 사용자 |
| 사용자의 핵심 목표 | 테마의 범위를 이해하고, 근거가 확인된 상장 종목 후보를 동일 기준으로 비교하기 |
| 서비스 목표 | 후보 선정 근거·정량 지표·출처·계산 기준을 한 결과 화면(또는 보고서)에서 제공하기 |
| 비목표 | 개인화 투자 자문, 자동 주문, 목표가 제시, 미래 수익 예측 |

## 4. MVP 범위

### 4.1 포함 기능

1. 사용자가 테마, 시장, 분석 기간, 최대 비교 종목 수를 입력한다.
2. 서비스가 테마의 범위·가치사슬·포함 및 제외 기준을 정의한다.
3. 공개 근거를 바탕으로 시장에 맞는 보통주 후보를 선정한다.
4. 후보별 테마 연결 근거와 출처를 제시한다.
5. 동일한 기준으로 가격·거래량·재무·밸류에이션 지표를 비교한다.
6. 핵심 뉴스 또는 공시와 출처 정보를 요약한다.
7. 데이터 기준일, 계산 방법, 데이터 한계, 투자 유의 문구를 결과에 포함한다.

### 4.2 제외 기능

- 로그인, 회원별 포트폴리오 관리, 관심 종목 저장
- 실시간 시세, 자동 매매, 알림 발송
- 유료·로그인·접근 제한 자료의 우회 수집
- ETF·ETN·우선주·SPAC·OTC 종목의 기본 포함
- 테마별 수익 전망, 종목 추천 점수, 매수·매도 의견

## 5. 사용자 입력 요구사항

| 입력값 | 형식 및 예시 | 필수 | 검증 규칙 |
| --- | --- | --- | --- |
| `theme` | 문자열, 예: `AI 반도체` | 예 | 공백만 입력할 수 없으며, 모호한 표현은 사용자에게 재확인을 요청한다. |
| `market` | `KR` 또는 `US` | 예 | `KR`은 한국 상장 보통주, `US`는 미국 거래소 상장 보통주를 기본으로 한다. |
| `period` | `1M`, `3M`, `6M`, `1Y`, `3Y` | 예 | 정의된 값만 허용한다. |
| `top_n` | 양의 정수 | 예 | 비교 최대 종목 수이며, 허용 범위는 구현 단계에서 확정한다. |

입력이 누락되거나 유효하지 않으면 분석을 시작하지 않고, 항목별 수정 방법을 안내한다.

## 6. 핵심 기능 요구사항

### FR-01. 테마 정의

- 서비스는 분석 전에 테마의 범위, 가치사슬, 포함 기준, 제외 기준을 한 문단으로 표시한다.
- 테마 관련성은 주가 변동이나 단순 기사 언급만으로 판단하지 않는다.
- 직접 수혜 기업과 간접 수혜 기업을 구분한다.

### FR-02. 후보 종목 선정

- 후보는 사업 직접성, 제품·서비스의 연관 근거, 테마 매출 또는 사업 비중 공개 여부, 상장 적격성을 기준으로 선정한다.
- 각 후보에 티커, 법인명, 거래소, 거래 통화, 테마 연결 근거를 표시한다.
- 사업 비중이 공개되지 않은 경우 `비중 미공개`로 표시한다.
- 후보가 `top_n`을 초과하면 공개 근거의 강도와 사업 직접성을 우선 기준으로 비교 대상을 제한한다.
- 의미 있는 제외 종목이 있으면 제외 사유를 짧게 기록한다.

### FR-03. 출처 관리

- 핵심 주장마다 출처 URL, 문서 제목, 발행일 또는 공시일, 확인일을 기록한다.
- 발행일을 확인할 수 없으면 `발행일 미확인`으로 표시한다.
- 출처 우선순위는 기업 공시·거래소 자료, 기업 IR·공식 보도자료, 정부·규제기관 자료, 신뢰 가능한 보조 자료 순이다.
- 접근 제한 또는 유료 자료는 우회하지 않으며, 공개 요약만 확인한 경우 그 한계를 표시한다.

### FR-04. 정량 데이터 비교

결과 비교표는 다음 지표를 포함한다.

| 지표 | 기본 기준 |
| --- | --- |
| 기간 수익률 | `(종료 조정종가 / 시작 조정종가 - 1) × 100` |
| 변동성 | 일간 수익률 표준편차 × `√252`의 연환산 값 |
| 최대낙폭(MDD) | `min(가격 / 직전 최고가격 - 1) × 100` |
| 거래량 변화 | 최근 20거래일 평균과 직전 20거래일 평균의 증감률 |
| 매출 성장률 | 가장 최근 공시 연간 또는 TTM의 전년 동기 대비 값 |
| 영업이익률 | `영업이익 / 매출액 × 100` |
| PER·PBR | 제공처의 기준일과 산식을 함께 표시 |

- 가격 데이터에는 제공처, 기준일, 거래소 시간대, 통화, 조정주가 사용 여부를 표시한다.
- 각 지표 열에는 기준일 또는 기준 기간을 표시한다.
- 음수 EPS 등으로 PER 비교가 불가능하면 `N/M`으로 표기하고 평균 계산에서 제외한다.
- 값이 없거나 공개되지 않은 경우 `N/A`, `확인 불가`, `비공개`를 상황에 맞게 구분한다.
- 데이터 누락, 거래정지, 상장폐지 등이 있으면 결측치를 0으로 대체하지 않으며, 제외 또는 마지막 거래일 사용 방식을 표에 명시한다.

### FR-05. 뉴스·공시 요약

- 후보 종목별 핵심 뉴스 또는 공시를 제공한다.
- 각 항목은 사실 중심의 한 줄 요약, URL, 발행일을 포함한다.
- 사실과 출처 기반 해석, 계산 결과를 구분해 작성한다.

### FR-06. 결과 구성

분석 결과는 아래 순서로 표시한다.

1. 빠른 요약: 최대 3줄, 테마 범위·비교 특징·주요 한계 또는 리스크
2. 핵심 포인트: 최대 3개, 출처 또는 비교표에서 확인된 사실
3. 테마 정의
4. 후보 종목 및 선정 근거
5. 정량 비교표
6. 핵심 뉴스·공시
7. 데이터 기준일·계산 방법·한계·리스크

`가장 유망`, `매수 기회`, `저평가 확실`처럼 투자 판단을 유도하는 표현은 사용하지 않는다.

## 7. 예외 처리 요구사항

| 상황 | 서비스 동작 |
| --- | --- |
| 필수 입력 누락 또는 형식 오류 | 분석을 중단하고 오류 항목과 허용 입력값을 안내한다. |
| 테마 범위가 모호함 | 임의로 해석하지 않고 사용자에게 테마 범위 확인을 요청한다. |
| 적격 후보를 찾지 못함 | 검색 범위와 제외 기준을 표시하고, 결과가 부족함을 안내한다. |
| 일부 지표 데이터 누락 | 가능한 지표만 표시하고 누락 사유와 비교 한계를 기록한다. |
| 출처 간 수치 상충 | 연결/별도, GAAP/비GAAP, 회계기간, 통화를 비교해 차이를 설명한다. |
| 접근 제한 자료 | 우회하지 않고 원문 미열람 사실과 공개 정보 기준의 한계를 표시한다. |

## 8. 비기능 요구사항

- **신뢰성:** 모든 핵심 주장과 수치가 출처 또는 명시된 산식으로 추적 가능해야 한다.
- **일관성:** 비교 대상 종목은 가능한 한 동일 시장·동일 거래일·동일 산식으로 계산한다.
- **투명성:** 데이터 제공처, 기준일, 통화, 단위, 조정 여부, 결측치 처리 방식을 표시한다.
- **보안:** API 키, 토큰, 계정 정보, 개인정보를 코드·결과·로그에 노출하지 않는다.
- **접근 준수:** 공개적으로 접근 가능한 정보만 사용하며, 유료·로그인·접근 제한 자료를 우회하지 않는다.
- **면책:** 결과 하단에 투자 조언이 아니며 독립적 추가 확인이 필요하다는 문구를 포함한다.

## 9. MVP 완료 기준

- [ ] 유효한 `theme`, `market`, `period`, `top_n` 입력을 받을 수 있다.
- [ ] 테마 정의와 후보 선정 근거를 출처와 함께 제공한다.
- [ ] 최대 `top_n`개 종목의 기본 식별 정보와 정량 비교표를 제공한다.
- [ ] 비교표의 지표별 기준일 또는 기준 기간, 단위, 계산 기준을 확인할 수 있다.
- [ ] 데이터 누락·상충·접근 제한 상황에서 결과 또는 오류 안내가 명확하다.
- [ ] 빠른 요약과 핵심 포인트에 투자 권유 표현이 없다.
- [ ] 결과에 데이터 한계와 투자 유의 문구가 포함된다.

## 10. 향후 결정이 필요한 항목

- 가격·재무·뉴스 데이터를 제공할 공개 데이터 소스와 호출 제한 정책
- `top_n`의 최소·최대 허용 범위
- 테마 후보 추출을 자동화할 수준과 사람이 검토하는 절차
- 결과 제공 형식(API 응답, 웹 화면, Markdown/PDF 보고서)
- 데이터 갱신 주기와 캐시 정책

## 11. 가정 및 제약

- 초기 MVP는 `KR`과 `US` 시장의 상장 보통주만 기본 대상으로 한다.
- 한국과 미국 종목을 한 표에서 비교하는 경우, 통화를 통일하거나 원통화 기준임을 명시한다. 환산 시 환율 출처·기준일·환산 방식을 표시한다.
- 공개 정보의 갱신 시점과 제공처별 정의 차이로 인해 결과는 이후 변경될 수 있다.
- 과거 수익률과 변동성은 미래 성과를 보장하지 않는다.
