# 테마 주식 리서치 에이전트 요구사항 정의서

- 작성자: Michelle
- 작성일: 2026-07-23
- 문서 상태: MVP 요구사항 초안

## 1. 서비스 목적

사용자가 입력한 주식 테마를 기준으로 한국 또는 미국의 상장 보통주 후보를 조사하고, 공개적으로 접근 가능한 근거와 정량 지표를 한 화면(또는 하나의 보고서)에서 비교할 수 있게 한다.

이 서비스는 정보 제공 및 리서치 보조 도구이며, 특정 종목의 매수·매도·보유를 권유하거나 미래 수익을 보장하지 않는다.

## 2. 대상 사용자와 해결하려는 문제

### 대상 사용자

- 관심 있는 산업·기술 테마의 상장 기업을 빠르게 비교하려는 개인 사용자
- 공개 출처를 바탕으로 후보 종목과 수치를 정리해야 하는 학습자

### 해결하려는 문제

- 테마와 실제 사업의 연결 근거를 여러 공시·IR·보도자료에서 직접 찾아야 한다.
- 가격 성과와 변동성, 재무·밸류에이션 지표를 동일한 기준으로 비교하기 어렵다.
- 결과를 검증할 수 있도록 주장별 출처와 데이터 기준일을 함께 관리하기 어렵다.

## 3. MVP 범위

### 반드시 제공하는 기능

1. 사용자는 `theme`, `market`, `period`, `top_n`을 입력해 리서치를 요청할 수 있다.
2. 서비스는 테마의 범위와 포함·제외 기준을 먼저 제시한다.
3. 서비스는 공개 근거가 확인된 상장 보통주 후보를 최대 `top_n`개 선정하고, 티커·거래소·법인명·통화·테마 연결 근거를 표시한다.
4. 서비스는 후보별 가격·거래량·재무·밸류에이션 지표를 동일 기준으로 비교한다.
5. 서비스는 각 핵심 주장과 뉴스·공시에 출처 URL, 문서 제목, 발행일(확인 불가 시 표시), 확인일을 제공한다.
6. 서비스는 데이터 기준일, 계산식, 결측치 처리, 비교 한계와 투자 유의 문구를 결과에 포함한다.

### MVP에서 제외하는 기능

- 로그인, 사용자별 저장·관심종목 관리
- 매매 주문 연동, 목표가·매수/매도 신호·추천 순위
- 유료 또는 로그인 필요 자료의 우회 수집
- ETF·ETN·우선주·SPAC·OTC의 기본 포함
- 실시간 시세 보장 및 자동화된 투자 의사결정

## 4. 입력 요구사항

| 항목 | 형식 | 필수 | 규칙 |
| --- | --- | --- | --- |
| `theme` | 문자열 | 예 | 분석할 테마명. 공백만 입력할 수 없다. |
| `market` | `KR` 또는 `US` | 예 | `KR`은 한국 상장 보통주, `US`는 미국 거래소 상장 보통주를 기본 범위로 한다. |
| `period` | `1M`, `3M`, `6M`, `1Y`, `3Y` | 예 | 가격 성과·변동성·MDD 계산 기간이다. |
| `top_n` | 양의 정수 | 예 | 비교할 최대 종목 수이다. |

- 필수값이 없거나 허용되지 않은 값이면 리서치를 실행하지 않고, 어떤 입력값을 수정해야 하는지 안내한다.
- ETF·ETN·우선주·SPAC·OTC는 사용자가 명시적으로 요청한 경우에만 분석 대상에 포함한다.

## 5. 후보 선정 요구사항

1. 후보의 테마 관련성은 주가 움직임이나 기사 언급만으로 판정하지 않는다.
2. 사업보고서·공시·IR 자료·제품/서비스 페이지·공식 보도자료 등에서 사업 또는 제품의 연결 근거를 확인한다.
3. 후보별로 사업 직접성(직접 수혜/간접 수혜), 테마 사업 비중의 공개 여부, 상장 적격성을 확인한다.
4. 후보가 `top_n`보다 많으면 공개 근거의 강도와 사업 직접성을 우선하여 비교 대상을 줄인다.
5. 사업 비중을 확인할 수 없으면 `비중 미공개`로 표시하며, 이를 근거 없이 순위화하지 않는다.

## 6. 정량 비교 요구사항

| 지표 | 계산 또는 표기 기준 |
| --- | --- |
| 기간 수익률 | `(종료 조정종가 / 시작 조정종가 - 1) × 100` |
| 변동성 | 기간 내 일간 수익률 표준편차에 `√252`를 곱한 연환산 변동성 |
| 최대낙폭(MDD) | `min(가격 / 직전 최고가격 - 1) × 100` |
| 거래량 변화 | 최근 20거래일 평균 거래량과 직전 20거래일 평균 거래량의 증감률 |
| 매출 성장률 | 최근 공시 연간 또는 TTM 기준 전년 동기 대비 성장률 |
| 영업이익률 | `영업이익 / 매출액 × 100` |
| PER·PBR | 제공처, 기준일, 산식(후행/선행)을 함께 표시 |

- 가격 데이터에는 제공처, 시작일·종료일, 기준일, 거래소 시간대, 통화, 조정주가 사용 여부를 표시한다.
- 조정 종가를 우선 사용하며, 불가능한 경우 비조정 종가임과 기업행동 반영 한계를 명시한다.
- 거래량 비교에 20거래일을 쓸 수 없으면 실제 사용 창을 표시한다.
- 결측치는 0으로 대체하지 않는다. 제외 또는 사용 가능한 마지막 거래일 대체 여부를 표에 명시한다.
- 음수 EPS로 PER 비교가 부적절하면 `N/M`으로 표시하고 평균 계산에서 제외한다.
- 수치가 없을 때는 성격에 따라 `N/A`, `N/M`, `비공개`, `확인 불가`를 구분해 쓴다.

## 7. 결과물 요구사항

결과는 아래 순서를 따른다.

1. **빠른 요약**: 최대 3줄. 테마 범위, 비교에서 확인된 특징, 주요 한계 또는 리스크를 각 1줄 이내로 작성한다.
2. **핵심 포인트**: 최대 3개. 출처 또는 비교표로 확인되는 사실만 작성한다.
3. **테마 정의**: 범위, 가치사슬, 포함·제외 기준, 분석 시장을 설명한다.
4. **후보 종목과 선정 근거**: 티커, 거래소, 법인명, 거래 통화, 직접성, 근거 및 출처를 제시한다.
5. **정량 비교표**: 수익률, 변동성, MDD, 거래량 변화, 매출 성장률, 영업이익률, PER, PBR을 표시한다. 각 열에 기준일 또는 기준 기간을 적는다.
6. **핵심 뉴스·공시**: 종목별 사실 요약, URL, 발행일을 제시한다.
7. **데이터 기준·계산 방법·한계·리스크**: 데이터 범위, 조정 여부, 결측치 처리, 산식, 비교 한계를 밝힌다.

## 8. 출처와 안전 요구사항

- 출처는 기업 공시·거래소 자료, 회사 IR·공식 보도자료, 정부·규제기관 자료, 신뢰 가능한 보조 자료 순으로 우선한다.
- 핵심 주장마다 URL, 문서 제목, 발행일 또는 `발행일 미확인`, 확인일을 남긴다.
- 출처 간 수치가 다르면 연결/별도, GAAP/비GAAP, 회계연도/분기, 통화 기준의 차이를 설명한다.
- 공개 접근이 불가능한 자료는 우회하지 않으며, 원문을 확인하지 못했다는 한계를 표시한다.
- API 키, 계정 정보, 개인정보, 유료 데이터 원문, 비공개·내부자 정보를 수집·저장·출력하지 않는다.
- `가장 유망`, `매수 기회`, `저평가 확실` 등 투자 판단을 유도하는 표현을 사용하지 않는다.

## 9. 예외 처리 요구사항

- 입력값 검증 실패: 오류 항목과 허용 형식을 안내하고 분석을 중단한다.
- 후보 부족: 확인된 후보만 제시하고 부족 사유를 표시한다.
- 가격 또는 재무 데이터 누락: 해당 지표를 `확인 불가` 또는 `N/A`로 표시하고 계산 제외 여부를 명시한다.
- 출처 접근 제한: 접근 제한 사실과 결과 해석의 한계를 기록한다.
- 상장폐지·거래정지·장기 휴장: 제외 또는 마지막 거래일 대체 방식을 명시한다.

## 10. 완료 기준

- 유효한 입력에 대해 필수 출력 7개 섹션이 순서대로 생성된다.
- 후보마다 상장 정보와 테마 연결 근거·출처를 확인할 수 있다.
- 정량 비교표의 모든 지표에 기준일 또는 기간과 결측치 표기가 적용된다.
- 빠른 요약은 3줄 이내, 핵심 포인트는 3개 이내이며 투자 권유 표현이 없다.
- 결과 끝에 공개 정보의 기준일 한계, 과거 성과의 한계, 테마 분류의 한계, 투자 조언이 아니라는 고지가 포함된다.

## 11. 검증 시나리오

| 구분 | 입력 또는 상황 | 기대 결과 |
| --- | --- | --- |
| 정상 | `theme=AI 반도체`, `market=KR`, `period=6M`, `top_n=5` | 최대 5개 후보와 근거·비교표·출처·한계가 포함된 결과를 생성한다. |
| 시장값 오류 | `market=JP` | 허용 값이 `KR`, `US`임을 알리고 실행하지 않는다. |
| 기간값 오류 | `period=2Y` | 허용 기간 목록을 안내하고 실행하지 않는다. |
| 수치 오류 | `top_n=0` 또는 문자열 | 양의 정수 입력을 요구하고 실행하지 않는다. |
| 데이터 누락 | 가격 또는 재무 지표를 확인할 수 없음 | 0으로 대체하지 않고 상태와 비교 한계를 표시한다. |
| 출처 제한 | 로그인·유료 자료만 존재 | 우회하지 않고 확인 불가 및 한계를 표시한다. |

## 12. 한계 및 고지

- 데이터는 공개 정보와 명시한 기준일 현재의 값이며 이후 변경될 수 있다.
- 과거 수익률과 변동성은 미래 성과를 보장하지 않는다.
- 기업의 다각화, 테마 사업 비중 비공개, 회계 기준·통화 차이로 비교에 한계가 있다.
- 본 결과는 투자 조언이 아니며, 의사결정 전 최신 공시와 독립적인 추가 확인이 필요하다.
