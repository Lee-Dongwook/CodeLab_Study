# 테마 주식 리서치 에이전트 요구사항 정의서

## 1. 문서 목적

본 문서는 테마 주식 리서치 에이전트의 MVP 범위와 기능 요구사항을 정의한다. 이 서비스는 공개적으로 접근 가능한 자료를 바탕으로 사용자가 입력한 주식 테마와 관련된 상장 종목 후보를 조사하고, 근거 및 정량 지표를 비교할 수 있도록 돕는다.

본 서비스의 결과는 정보 제공 및 리서치 보조용이며, 투자 자문이나 매수·매도 권유가 아니다.

## 2. 문제 정의

사용자는 특정 테마와 관련된 종목을 찾을 때 기사 언급이나 커뮤니티 정보만으로 기업의 실제 사업 연관성을 판단하기 어렵다. 또한 여러 종목의 가격 흐름과 재무 지표를 같은 기준으로 비교하고, 그 근거가 되는 공시·IR 자료를 함께 확인하기 어렵다.

서비스는 이 문제를 해결하기 위해 다음을 제공한다.

- 기업의 공개 공시, IR, 공식 보도자료 등으로 확인한 테마 연관 근거
- 동일 기준으로 계산한 가격·거래량·재무·밸류에이션 비교값
- 데이터 기준일, 계산 방법, 출처 및 한계가 명시된 리서치 결과

## 3. 대상 사용자

- 특정 산업 또는 투자 테마를 조사하는 개인 사용자
- 수업·프로젝트에서 공개 정보 기반의 주식 리서치 결과를 정리해야 하는 사용자

사용자는 투자 전문가가 아닐 수 있으므로, 결과 화면은 수치뿐 아니라 선정 근거와 한계를 쉬운 문장으로 함께 제시해야 한다.

## 4. 서비스 목표와 비목표

### 4.1 목표

1. 사용자가 테마, 시장, 분석 기간, 비교 종목 수를 입력하면 근거 있는 후보 종목을 제시한다.
2. 후보별 테마 관련성의 출처와 직접성(직접 수혜/간접 수혜)을 확인할 수 있게 한다.
3. 가격 성과, 위험 지표, 거래량 변화, 재무·밸류에이션 정보를 같은 기준으로 비교한다.
4. 모든 핵심 결과에 출처, 기준일, 계산 방법, 데이터 한계를 남긴다.

### 4.2 비목표

- 매수·매도·보유 의견, 목표주가, 수익 보장 등 투자 판단을 제시하지 않는다.
- 비공개 정보, 내부자 정보, 로그인·유료 구독이 필요한 자료를 우회하여 수집하지 않는다.
- ETF, ETN, 우선주, SPAC, OTC 종목은 사용자가 별도로 요청하지 않는 한 분석 대상에 포함하지 않는다.
- MVP에서 로그인, 개인 포트폴리오 관리, 자동 매매, 알림 기능은 구현하지 않는다.

## 5. 입력 요구사항

분석 요청은 아래 네 필수 값을 포함해야 한다.

| 필드 | 설명 | 허용값 또는 예시 | 검증 규칙 |
| --- | --- | --- | --- |
| `theme` | 조사할 주식 테마 | `AI 반도체`, `전기차 배터리` | 공백만으로 구성될 수 없으며, 누락 시 요청을 진행하지 않는다. |
| `market` | 분석 시장 | `KR`, `US` | 두 값 이외의 입력은 오류로 처리한다. |
| `period` | 가격 분석 기간 | `1M`, `3M`, `6M`, `1Y`, `3Y` | 지원하지 않는 형식은 오류로 처리한다. |
| `top_n` | 최대 비교 종목 수 | 양의 정수 | 양의 정수인지 확인하고, 서비스가 정한 최대값을 초과하면 재입력을 요청하거나 제한값을 안내한다. |

- `KR`은 한국 거래소 상장 보통주, `US`는 미국 거래소 상장 보통주를 기본 대상으로 한다.
- 입력이 누락되거나 뜻이 모호하면 임의로 보정하지 않고 사용자에게 확인을 요청한다.
- 분석 요청에는 선택적으로 ETF·ETN·우선주·SPAC·OTC 포함 여부를 받을 수 있으나, 기본값은 모두 제외이다.

## 6. 핵심 기능 요구사항

### FR-01. 테마 범위 정의

- 시스템은 조사 시작 시 테마의 범위, 가치사슬, 포함 기준, 제외 기준을 한 문단으로 작성한다.
- 테마의 해석이 여러 가지일 경우, 사용한 해석과 제외한 해석을 결과에 명시한다.

### FR-02. 후보 종목 수집 및 적격성 확인

- 시스템은 공개 자료를 바탕으로 테마 관련 후보를 수집한다.
- 각 후보에 대해 티커, 법인명, 거래소, 거래 통화, 보통주 여부, 상장 시장을 확인한다.
- 상장 적격성이나 식별 정보가 확인되지 않은 후보는 비교 대상에서 제외하고, 필요하면 제외 사유를 표시한다.

### FR-03. 테마 관련성 검증

- 테마 관련성은 회사의 사업보고서, 공시, IR 자료, 제품·서비스 페이지, 공식 보도자료로 검증한다.
- 단순 기사 언급이나 주가 변동만으로 관련 종목으로 분류하지 않는다.
- 각 후보에는 테마 연결 근거, 직접성 구분(직접 수혜/간접 수혜), 출처 URL, 문서 제목, 발행일 또는 공시일, 확인일을 기록한다.
- 테마 관련 매출 또는 사업 비중이 공개되지 않은 경우 `비중 미공개`로 표기한다.

### FR-04. 비교 대상 선정

- 후보가 `top_n`보다 많을 경우, 공개 근거의 강도와 사업 직접성을 우선하여 비교 대상을 선정한다.
- 선정 결과는 투자 추천 순위처럼 표현하지 않는다.
- 주요 후보가 제외된 경우에는 짧은 제외 사유를 제공할 수 있다.

### FR-05. 시장 데이터 수집 및 계산

- 각 비교 종목에 대해 기간 시작일과 종료일의 가격 데이터, 일별 가격, 일별 거래량을 수집한다.
- 가격 데이터에는 제공처, 기준일, 거래소 시간대, 통화, 조정 종가 사용 여부를 표시한다.
- 조정 종가를 사용할 수 있으면 배당·분할 등 기업행동이 반영된 조정 종가를 우선 사용한다.
- 제공처에서 조정 종가를 제공하지 않으면 비조정 종가임을 명시한다.
- 산출 지표는 아래 기준을 사용한다.

| 지표 | 계산 기준 |
| --- | --- |
| 기간 수익률 | `(종료 조정종가 / 시작 조정종가 - 1) × 100` |
| 연환산 변동성 | 기간 내 일간 수익률 표준편차 × `√252` |
| 최대낙폭(MDD) | `min(가격 / 직전 최고가격 - 1) × 100` |
| 거래량 변화 | 최근 20거래일 평균 거래량과 직전 20거래일 평균 거래량의 증감률 |

- 분석 기간이 40거래일보다 짧으면 실제 사용한 거래일 수를 결과에 표시한다.
- 결측치, 거래정지, 상장폐지, 장기 휴장 데이터는 0으로 대체하지 않는다. 제외 또는 마지막 사용 가능 거래일 대체 여부와 방식을 표시한다.

### FR-06. 재무 및 밸류에이션 데이터 비교

- 매출 성장률과 영업이익률은 가장 최근 공개된 연간 또는 TTM 기준을 우선 사용한다.
- 각 수치에는 회계 기준 기간, 단위, 연결/별도 여부를 표시한다.
- 영업이익률은 `영업이익 / 매출액 × 100`으로 계산한다.
- PER·PBR은 제공처, 기준일, 산식(후행/선행 및 보통주 기준)을 표시한다.
- 음수 EPS 등으로 PER이 의미 없으면 `N/M`으로 표기하고 평균 계산에서 제외한다.
- 확인할 수 없는 값은 `확인 불가`, 공개되지 않은 값은 `비공개`, 적용할 수 없는 값은 `N/A`로 구분한다.

### FR-07. 출처 및 뉴스·공시 제공

- 종목별로 테마 관련성 또는 비교 해석에 중요한 뉴스·공시를 제공한다.
- 각 항목은 종목명, 한 줄 요약, URL, 문서 제목, 발행일 또는 공시일을 포함한다.
- 유료·로그인·접근 제한 자료는 우회하지 않으며, 공개 요약만 확인 가능하면 그 한계를 표시한다.

### FR-08. 결과 보고서 생성

분석 결과는 아래 순서로 출력한다.

1. 빠른 요약: 최대 3줄, 테마 범위·비교 결과 특징·주요 한계 또는 리스크를 각각 포함한다.
2. 핵심 포인트: 최대 3개, 출처 또는 비교표에서 확인된 사실만 제시한다.
3. 테마 정의: 분석 범위, 가치사슬, 포함·제외 기준, 대상 시장을 제시한다.
4. 후보 종목과 선정 근거: 식별 정보, 직접성, 연결 근거와 출처를 제시한다.
5. 정량 비교표: 가격·거래량·재무·밸류에이션 지표를 표시한다.
6. 핵심 뉴스·공시: 종목별 사실과 출처를 제시한다.
7. 데이터 기준일·계산 방법·한계·리스크: 데이터 범위와 처리 방식을 설명한다.

- 정량 비교표의 모든 열에는 기준일 또는 기준 기간을 표시한다.
- 빠른 요약 및 핵심 포인트에는 `가장 유망`, `매수 기회`, `저평가 확실` 등 투자 판단을 유도하는 표현을 사용하지 않는다.

## 7. 출력 데이터 요구사항

정량 비교표는 최소한 다음 열을 포함한다.

| 분류 | 필수 항목 |
| --- | --- |
| 종목 식별 | 티커, 법인명, 거래소, 통화, 직접성 구분 |
| 가격·위험 | 기간 수익률, 연환산 변동성, MDD |
| 거래량 | 최근/직전 평균 거래량 기준의 변화율, 사용 창 |
| 재무 | 매출 성장률, 영업이익률, 적용 회계 기간 및 단위 |
| 밸류에이션 | PER, PBR, 기준일·산식 |
| 근거 | 테마 연결 근거, 출처 URL, 문서 발행일 또는 공시일 |

시장 간 비교가 필요한 경우에는 원통화 기준인지, 환산했는지 명시한다. 환산을 수행했다면 환율 출처·기준일·환산 방식을 함께 제공한다.

## 8. 예외 처리 요구사항

| 상황 | 처리 방식 |
| --- | --- |
| 필수 입력 누락 또는 형식 오류 | 어떤 필드가 유효하지 않은지 알리고 분석을 시작하지 않는다. |
| 테마 범위가 모호함 | 가능한 해석을 확인하도록 요청하고 임의로 확정하지 않는다. |
| 조건을 충족하는 후보 없음 | 후보가 없다는 사실과 검색·제외 기준을 제공한다. |
| 일부 시장 데이터 누락 | 해당 지표를 `확인 불가`로 표시하고, 비교 가능성의 한계를 설명한다. |
| 출처 간 수치 불일치 | 연결/별도, GAAP/비GAAP, 회계 기간, 통화를 비교해 차이를 설명하며 임의 선택하지 않는다. |
| 접근 제한 자료 | 우회하지 않고 열람 불가 사실과 공개 확인 범위를 표시한다. |

## 9. 비기능 요구사항

### 9.1 신뢰성 및 재현성

- 핵심 주장과 정량 수치는 모두 출처 또는 계산 기준을 추적할 수 있어야 한다.
- 동일 입력과 동일 데이터 기준일에서는 같은 계산식과 표시 규칙을 적용해야 한다.
- 사실, 출처 기반 해석, 계산 결과를 문서상 구분해야 한다.

### 9.2 보안 및 개인정보

- API 키, 토큰, 비밀번호, 계정 정보, 개인정보를 코드·결과·로그에 노출하지 않는다.
- 환경 변수는 실제 값이 아닌 예시 값만 포함하는 `.env.example` 형태로 안내한다.

### 9.3 안전한 표현

- 결과는 투자 조언이 아니라는 고지를 포함한다.
- 과거 성과가 미래 성과를 보장하지 않는다는 점을 명시한다.
- 근거 없는 전망, 확정적 인과관계, 추천 순위 표현을 사용하지 않는다.

## 10. MVP 범위와 완료 기준

MVP는 단일 테마, 단일 시장(`KR` 또는 `US`)을 대상으로 다음을 수행하면 완료로 본다.

1. 네 개 필수 입력값을 검증한다.
2. 공개 근거가 있는 후보 종목을 최대 `top_n`개 선정한다.
3. 종목별 테마 연결 근거와 출처를 제공한다.
4. 기간 수익률, 변동성, MDD, 거래량 변화, 매출 성장률, 영업이익률, PER, PBR을 가능한 범위에서 비교한다.
5. 기준일·계산식·결측치 처리·한계·투자 유의사항을 포함한 결과 보고서를 출력한다.

- [ ] 테마 관련성의 출처 URL, 문서 제목, 발행일 또는 공시일, 확인일이 있는가?

- [ ] 가격 데이터의 시작일·종료일, 조정 여부, 통화, 제공처가 표시되었는가?

## 12. 공통 고지 문구

데이터는 공개 정보와 명시한 기준일 현재의 값이며 이후 변경될 수 있다. 과거 수익률과 변동성은 미래 성과를 보장하지 않는다. 테마 분류는 기업의 다각화, 사업 비중 비공개, 회계 기준 및 통화 차이로 제한될 수 있다. 본 결과는 투자 조언이 아니며, 의사결정 전 최신 공시와 독립적인 추가 확인이 필요하다.
