# 테마 주식 리서치 에이전트 기능 분해 명세

## 1. 문서 목적

이 문서는 `requirements.md`의 MVP 요구사항을 구현 가능한 기능 단위로 나눈다. 핵심 흐름은 국내(KRX) 테마 종목 리서치이며, 미국 시장·Peer Company·글로벌 운용사 정보는 국내 분석 결과를 보완하는 참고 정보로 처리한다.

## 2. 전체 처리 흐름

```text
입력 검증
→ 국내 테마 정의
→ 국내 후보 종목 선정
→ 국내 정량 비교
→ 리스크·뉴스·공시 정리
→ 미국 참고 정보 수집
→ 결과 보고서 생성
```

국내 후보 종목 선정과 국내 분석 결과를 먼저 완료한다. 미국 참고 정보가 없더라도 국내 분석 결과는 제공할 수 있어야 한다.

## 3. 입력과 공통 출력

### 3.1 입력

| 입력값 | 설명 | 검증 기준 |
| --- | --- | --- |
| `theme` | 분석할 테마 또는 국내 종목명 | 빈 값이 아니어야 한다. |
| `top_n` | 비교할 최대 국내 후보 종목 수 | 1 이상의 정수여야 한다. |

### 3.2 공통 출력 규칙

- 공개적으로 확인 가능한 자료만 사용한다.
- 모든 수치와 참고 정보에 데이터 기준일 또는 문서 발행일을 표시한다.
- 확인하지 못한 값은 `확인 불가`로 표시한다.
- 투자 추천, 목표가, 매수·매도 의견은 제공하지 않는다.

## 4. 핵심 기능

### F-01. 입력 검증

| 구분 | 내용 |
| --- | --- |
| 입력 | `theme`, `top_n` |
| 처리 | 빈 테마·종목명, 유효하지 않은 `top_n`, 의미가 모호한 입력을 확인한다. |
| 출력 | 유효한 분석 요청 또는 수정이 필요한 입력 항목 안내 |

### F-02. 국내 테마 정의

| 구분 | 내용 |
| --- | --- |
| 입력 | 검증된 테마 또는 국내 종목명 |
| 처리 | 테마 설명과 국내 종목 포함 기준을 공개 기업 자료로 정리한다. 국내 종목명이 입력된 경우 해당 기업의 사업을 기준으로 연관 테마를 정의한다. |
| 출력 | 국내 테마 설명, 포함 기준, 근거 출처 |

### F-03. 국내 후보 종목 선정

| 구분 | 내용 |
| --- | --- |
| 입력 | 국내 테마 정의, `top_n` |
| 처리 | 기업 공시, IR, 공식 보도자료, 제품·서비스 페이지에서 사업 연관성을 확인한다. KRX 상장 보통주만 대상으로 하며, 근거의 명확성과 직접성을 기준으로 최대 `top_n`개를 선정한다. |
| 출력 | 종목명, 종목코드, 테마 관련 사업, 직접/간접 관련 여부, 선정 근거, 출처 |

### F-04. 국내 기본 정량 비교

| 구분 | 내용 |
| --- | --- |
| 입력 | 국내 후보 종목 목록 |
| 처리 | 동일 기준일에 가능한 범위에서 최신 시장·재무 데이터를 수집한다. |
| 출력 | 최근 종가, 시가총액, PER, PBR, 최근 매출 성장률, 영업이익률, 각 기준일 또는 재무 기준 기간 |

### F-05. 가격 및 거래량 분석

| 구분 | 내용 |
| --- | --- |
| 입력 | 국내 후보 종목 목록, 가격·거래량 데이터 |
| 처리 | 모든 후보에 같은 내부 기준 기간을 적용하여 가격·거래량 변화를 비교한다. 사용한 기준 기간과 기준일을 함께 기록한다. |
| 출력 | 기간 수익률, 변동성, 거래량 변화, 최근 거래량 급증 여부, 기준 기간, 기준일 |

### F-06. 상세 리스크 분석

| 구분 | 내용 |
| --- | --- |
| 입력 | 국내 후보, 공시, 뉴스, 기업 공개 자료 |
| 처리 | 공개자료에서 확인되는 종목별 이슈와 산업 공통 위험을 사실 중심으로 정리한다. |
| 출력 | 최근 주요 리스크 요인, 공시·뉴스 기반 주요 이슈, 산업 특성상 위험, 투자 전 확인 체크포인트, 출처 |

### F-07. 최근 뉴스 및 공시 수집

| 구분 | 내용 |
| --- | --- |
| 입력 | 국내 후보 종목 목록 |
| 처리 | 각 후보의 최근 뉴스 또는 공시를 1~3건 선택하고 사실 중심의 한 줄 요약을 작성한다. |
| 출력 | 종목명, 문서 제목, 한 줄 요약, URL, 발행일 또는 공시일 |

## 5. 참고 정보 기능

참고 정보 기능은 국내 후보 선정과 국내 분석을 대체하지 않는다. 자료가 없거나 연관성을 확인할 수 없으면 해당 섹션에 확인 가능한 공개자료가 없음을 표시한다.

### R-01. 미국 시장 선행 동향

| 구분 | 내용 |
| --- | --- |
| 입력 | 국내 테마 정의 |
| 처리 | 전일 미국 시장에서 동일하거나 유사한 테마의 흐름과 상승·하락 배경을 공개자료로 확인한다. |
| 출력 | 전일 테마 동향, 주요 배경, 미국 대표 종목, 대표 ETF(있는 경우), 주요 뉴스 요약, 출처와 기준일 |

### R-02. 관련 미국 Peer Company

| 구분 | 내용 |
| --- | --- |
| 입력 | 국내 테마 또는 국내 후보 종목 |
| 처리 | 사업 영역, 제품, 기술, 고객사, 공급망 등 객관적인 연관성을 기준으로 미국 상장기업을 찾는다. 추천이나 순위화는 하지 않는다. |
| 출력 | 기업명·티커, 관련 사업, 국내 종목 또는 테마와의 연관성, 직접/간접 관련 여부, 출처와 기준일 |

### R-03. 글로벌 운용사 동향

| 구분 | 내용 |
| --- | --- |
| 입력 | 국내 테마 정의 |
| 처리 | BlackRock, Vanguard, Fidelity, State Street 등 운용사의 공개 리포트, ETF 구성 종목, 13F 공시를 확인한다. 테마와의 관련성이 확인된 자료만 사용한다. |
| 출력 | 운용사명, 관련 ETF 편입 현황, 공개 보유 종목, 공개 리포트·시장 의견, 최근 운용 동향, 출처와 기준일 |

## 6. 결과 보고서 조합

| 순서 | 섹션 | 사용하는 기능 |
| --- | --- | --- |
| 1 | 빠른 요약 | F-02 ~ F-06 |
| 2 | 국내 테마 정의 | F-02 |
| 3 | 국내 후보 종목 및 선정 근거 | F-03 |
| 4 | 국내 정량 비교 | F-04, F-05 |
| 5 | 상세 리스크 분석 | F-06 |
| 6 | 미국 시장 선행 동향 (참고) | R-01 |
| 7 | 관련 미국 Peer Company (참고) | R-02 |
| 8 | 글로벌 운용사 동향 (참고) | R-03 |
| 9 | 최근 뉴스 및 공시 | F-07 |
| 10 | 참고자료 및 출처 | F-02 ~ F-07, R-01 ~ R-03 |

## 7. 구현 우선순위

### 1차: 국내 리서치 핵심 흐름

- F-01 입력 검증
- F-02 국내 테마 정의
- F-03 국내 후보 종목 선정
- F-04 국내 기본 정량 비교
- F-07 최근 뉴스 및 공시 수집
- 결과 보고서의 1~4, 9~10번 섹션 생성

### 2차: 국내 분석 확장

- F-05 가격 및 거래량 분석
- F-06 상세 리스크 분석
- 결과 보고서의 5번 섹션 생성

### 3차: 참고 정보 확장

- R-01 미국 시장 선행 동향
- R-02 관련 미국 Peer Company
- R-03 글로벌 운용사 동향
- 결과 보고서의 6~8번 참고 섹션 생성

## 8. MVP 제외 범위

- 미국 시장 전체 종목의 정량 비교 또는 미국 시장 단독 리서치
- 실시간 시세, 자동 매매, 알림, 로그인 및 관심종목 저장
- ETF·ETN·우선주·SPAC·OTC의 국내 후보 편입
- 투자 추천, 목표가, 매수·매도 의견
- 복잡한 통계 모델, 환율 변환, 회계기준 비교
